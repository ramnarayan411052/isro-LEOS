# DynamiQ manufacturing dashboard

DynamiQ is a React dashboard for manufacturing task scheduling and workforce operations.

## Run the React app

Install Node.js, then from this folder run:

```bash
npm install
npm run dev
```

Open the local address printed by Vite. The React app stores its demo jobs, schedule, operators, and completed-task archive in browser local storage.

The app uses illustrative data. Schedule generation demonstrates heuristic sorting and does not execute a trained DQN model. Jobs, schedules, operators, and completed tasks are stored in browser local storage.
